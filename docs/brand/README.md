# TrueNorth brand assets

- `truenorth-mark.svg` — mark on light backgrounds (neutral ring, north needle in accent blue `#2E47C9`).
- `truenorth-mark-dark.svg` — mark on dark backgrounds (needle `#8C9BF5`).
- `truenorth-app-icon.svg` — 512×512 app icon, full-bleed `#171D2E` background, safe as a PWA *maskable* icon (the mark fits inside the central 80 %).

The 192 px and 512 px PNGs for the web manifest are generated in phase 0 from `truenorth-app-icon.svg`.
